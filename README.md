# Ondo State IGR-GDP Analysis

## Overview

This project investigates the relationship between Internally Generated Revenue (IGR) and Gross Domestic Product (GDP) in Ondo State using R.

## Objectives

- Examine the trend of IGR.
- Examine the trend of GDP.
- Determine the relationship between IGR and GDP.
- Estimate the effect of IGR on GDP.
- Model volatility using GARCH and EGARCH.
